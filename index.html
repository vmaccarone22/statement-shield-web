Questions

Short answers — we’ll fill in the rest on a call.

Do my merchants’ files get uploaded to you?

No. The readout runs on the computers you control. You pick the folder or files each time.

Does this replace my funders’ portals?

No. We help you prepare a file you can stand behind. You still submit the way each funder wants.

Is this built for cash advance?

Yes — the language and layouts match how advance shops read statements and scrubs every day.

What do we install on?

Today’s product is built for Windows PCs your shop already uses. The team option adds shared calendars and phone reminders when you’re ready.

Can you match our application or how we package deals?

We’ll work with you. You can generate a clean application PDF in the app or use your existing PDF — we help wire it up during onboarding.
