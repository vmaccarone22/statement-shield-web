Security & data handling

Underwriting software touches sensitive financial documents. We describe posture plainly so compliance and ownership can sign off.

  • Core (desktop): Files stay on hardware you control. Analysis uses only the PDFs and folders you explicitly run — no mandatory cloud corpus of your merchants’ statements.
  • CRM tier (optional): When you enable server-backed collaboration, scope networking, backups, access controls, and calendar-backed callbacks as part of enterprise onboarding — not as a footnote.
  • Vendor hygiene: Image handling stays local where you configure it; outbound links for public checks open in the user’s browser — no silent third-party data brokerage from this product surface.

Frequently asked

Straight answers — update contact details on this page before you go live publicly.

Is there a free trial?

Yes. Core includes a free two-week trial on your own Windows machines. Many SaaS underwriters advertise a 14-day hosted trial instead — same idea (eval before you buy), except ours never requires you to load the merchant book into a shared tenant just to get started.

Does Core upload my merchants’ files to your servers?

No. Underwriting runs on the workstation. You choose folders or individual PDFs/images each time. A merchant workspace is optional — it only powers fast search and the deal board when you point the app at your rep directory.

Do you replace my funders’ portals?

No. Fund Pilot helps you prepare and defend a file. Submissions still follow each funder’s process.

Is this only for MCA?

The scoring language and layouts are built for cash-advance underwriting. Other products may be added later, but the product is purpose-built for advance shops.

Cloud or desktop?

Core is built as a desktop workstation on Windows with per-ISO workspace configuration. CRM unlocks optional server-backed team workflows when you’re ready — same brand, staged rollout, with shared calendars and mobile apps for notifications.

How is this different from cloud statement-as-a-service products?

Those products optimize for remote ingestion, multi-tenant pipelines, and often metered per-document pricing. Fund Pilot Core optimizes for local files, your workspace paths, and MCA-specific depth without a mandatory cloud corpus — add CRM only when your team needs shared truth and mobile pings.

Mac, iPhone, Android?

Core ships for Windows today and is built for easy rollout across your reps. Core + CRM includes shared calendars and follow-ups; native iOS and Android apps are on the roadmap so reps get push nudges when a merchant is due for a return call — matching the desktop follow-up planner.

Can you match our brokerage’s application or lender workflow?

We’ll work with you. Core ships with a flexible, Fund Pilot–branded PDF you generate in-app from typed fields; many ISOs still pair that with their existing static PDF under Workspace. On onboarding and enterprise tiers we can help align labels, sections, and hand-off so it fits how your shop packages deals — without replacing each funder’s submission portal.

Do you support CSV, QFX, or OFX — not just PDF?

Core is optimized for PDF and image statements. CSV, QFX, and OFX feeds — plus deterministic import maps — are part of enterprise / CRM-tier scoping when your warehouse already standardizes on those exports.

Is there an API like cloud products do?

Yes, when you need it. Core + CRM can ship with REST endpoints and webhooks for deals, merchants, and callbacks. We turn them on with documentation and boundaries so compliance gets a say — not as a public-by-default multi-tenant pipe.

Why does Fund Pilot cost more than $99/mo cloud parsers?

Those tools optimize for hosted parsing and often make money on per-statement caps and overages. Fund Pilot is desk software: analysis stays on hardware you control, volume on licensed machines is unlimited in Core, and rollout + 24/7 humans are bundled — so our floor price is higher by design. If lowest monthly row is the primary buying criterion, we’re probably not the right vendor.

What do we need before go-live?

We’ll send a short checklist (domain, contact email, and a few housekeeping items) once you’re ready to point customers at the site.
